Kebijakan Privasi

Terakhir diperbarui: 25 November 2026

Kebijakan ini menjelaskan bagaimana LeadMarket Ads Dashboard mengelola informasi saat admin menghubungkan akun iklan Meta dan saat pengunjung melihat dashboard.

Informasi yang dikelola

  • Informasi akun admin seperti nama dan alamat email untuk login.
  • Nama brand serta ID dan nama akun iklan Meta yang dipilih admin.
  • Data laporan iklan yang diminta dari Meta, seperti belanja iklan, impresi, klik tautan, dan metrik CTR.
  • Token akses Meta yang diperlukan untuk mengambil laporan. Token disimpan terenkripsi di server.

Penggunaan informasi

Informasi digunakan untuk mengautentikasi admin, menghubungkan akun iklan, menampilkan dan membandingkan metrik iklan, serta menjaga keamanan dan operasional dashboard.

Dashboard untuk pengunjung

Pengunjung dapat melihat dashboard tanpa login. Informasi brand dan metrik yang ditampilkan pada dashboard dapat dilihat oleh siapa pun yang memiliki tautan dashboard. Admin sebaiknya hanya menghubungkan akun dan menampilkan data yang memang boleh dibagikan melalui dashboard tersebut.

Penyimpanan dan layanan pihak ketiga

Data aplikasi disimpan di Neon dan aplikasi di-host di Render. Saat admin menghubungkan akun, Meta memproses login dan permintaan data sesuai ketentuan Meta. Kami tidak menjual data pribadi atau token akses.

Retensi dan penghapusan

Informasi disimpan selama diperlukan untuk menyediakan dashboard. Admin dapat menghapus brand beserta data terkait dari dashboard. Untuk meminta penghapusan informasi akun atau koneksi Meta, lihat Instruksi Penghapusan Data.

Keamanan

Akses pengelolaan brand dibatasi untuk admin yang masuk. Token Meta disimpan terenkripsi di server. Tidak ada metode penyimpanan atau pengiriman data yang dapat dijamin sepenuhnya bebas risiko.
